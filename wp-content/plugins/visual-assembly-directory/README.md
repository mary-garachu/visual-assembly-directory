# Visual Assembly Directory

A WordPress plugin demonstrating custom post types, templates, and dynamic content handling.

## Features

- **Custom Post Type:** `visual_assembly` with Title, Featured Image, Excerpt, and Content.
- **Posts Directory:** Responsive 3-column grid (1 column on mobile) with archive and single post pages.
- **Events Feed:** Displays upcoming events from a JSON file (`sample_events.json`), sorted by date in a responsive layout.
- Fully responsive and styled with separate CSS files for posts and events.
- Built to work with the Twenty Twenty-Four theme.

## Usage

1. Place the plugin in `wp-content/plugins/` and activate it.
2. Add posts under **Visual Assemblies**.
3. Create a page using the **Events Feed** template to display upcoming events.

## Technologies

- WordPress plugin development
- PHP, HTML, CSS
- JSON data handling
- Responsive CSS grid layout
